# 运行时计划与证据

生成配置前，按任务需要准备当前任务条件、路线、阶段、账号选择和执行策略。以下输入适用于通常任务、限时任务和活动海域。

## 本次所需输入

| 用途 | 输入内容 |
| --- | --- |
| 确认任务目标 | 任务编号、完整标题、次数和当前进度 |
| 选择编成与装备 | 舰船与装备实例、保留分配、贴条兼容性 |
| 设计路线与战斗策略 | 当前地图、阶段、难度、路线与节点策略 |
| 核验航空队与战斗条件 | 陆航目标航程、敌编成、增伤和当前开放状态 |
| 安排执行流程 | 练级角色、配装、优先级、远征步骤与完成记录 |

通常地图的 `NormalMapFacts` 仅提供待核对的节点参考，不包含任务方案。`Source` 是公开资料核对入口，不表示已完成当前版本核验；缺失或存疑的节点类型仍须核对。该表不证明某条路线当前可达，也不会自动生成路线规格。活动资料更新、任务条件变更或账号状态变化后，重新查证相关输入。

## 证据文件位置

先按 [公共规则](公共规则.md) 明确本次工作区或证据文件路径。使用工作区时，设置 `<WORKSPACE_ROOT>` 和 `KCPS_WORKSPACE`，工具约定的默认路线证据位置为 `<WORKSPACE_ROOT>/.work/route-overrides.json`。私人文件不得放入 `<SKILL_ROOT>`。

读取路径优先级为调用参数（支持该参数的工具）、`KCPS_ROUTE_OVERRIDES` 环境变量、显式选择的本机设置中的 `RouteOverridesPath`，然后是明确指定工作区的 `.work/route-overrides.json`。工作区由 `KCPS_WORKSPACE` 或显式设置文件中的 `WorkspaceRoot` 提供。没有指定来源时不搜索周边目录，也不加载私人覆盖；显式指定的文件不存在时报错，不回退到其他方案。

证据文件由调用方明确选择和管理。复用任何已有资料前，核对其适用地图、阶段、账号状态和时效，不能仅按文件位置判断资料是否适用。

## 路线证据结构

`route-overrides.json` 是 JSON 对象，以下键按需要提供：

| 键 | 内容与合并方式 |
| --- | --- |
| `Routes` | 路线规格数组；每项 `Id` 必须非空且唯一。相同 `Id` 合并，其他项追加。工具未预置任务路线，正常运行须提供本次规格。 |
| `DisabledRouteIds` | 要禁用的旧规格 ID 数组，防止旧方案继续参与匹配。 |
| `EventBossStages` | 当前活动 Boss 点所属阶段数组；声明时整体替换相应列表。每项包含 `Id`、`Area`、`RouteSpecIdRegex`、`BossPoints`（点名到阶段号）、`Source`、`LastVerifiedJst` 和 `RefreshAfterDays`。 |
| `RouteBranchRules` | 当前分歧证据数组；声明时整体替换。包含 `KcNavMap`、`From`、`To`、公式、系数、阈值、比较方式、`Evidence` 和核对日期等适用字段。 |
| `LandBasedAirCorpsTargetRadii` | 陆航目标航程证据对象，结构见下文；按路线规格 `Id` 合并。 |

路线规格至少要能唯一对应当前配置：保存 `Id`、`Sea`、`Area`、`KcNavMap`、准确的 `GroupNameRegex`、`Source`、`LastVerifiedJst`、`RefreshAfterDays`，并填写实际路线与逐进入边的 `Nodes`。完整的通常路线要求见 [通常出击配置](通常出击配置.md)，活动阶段、标签、索敌、陆航及停止条件见 [活动海域出击配置](活动海域出击配置.md)。

不要使用宽泛任务名正则让多个方案误匹配，也不要按列表先后选取第一条。缺少路线、同时匹配多个规格或必需节点条件缺失时，先补齐证据再交付；不能用允许缺路线的旧配置检查选项绕过新配置验收。

## 独立航程证据

`LandBasedAirCorpsTargetRadii` 包含 `Version: 1` 与 `Routes` 对象。`Routes` 的键为路线规格 `Id`，值保存：

- `Map`：与路线规格 `KcNavMap` 完全一致的 KCNav 地图号。
- `Source`、`LastVerifiedJst`：目标航程的外部资料及核对日期。
- `Corps`：以基地航空队编号为键，每项保存实际 `TargetPoints` 和数值 `RequiredRadius`。

同一队分投多个点时，`RequiredRadius` 取各波目标所需航程的最大值。证据必须先独立查证，再供生成器和校验器读取；不能从最终配置或备注反向复制一个数字后称作独立核验。工具未预置目标航程，须提供本次证据。

## 策略是输入，不是历史默认值

当前配置需要的循环次数、士气、修理、夜战、熟练度和支援策略写入 `StageDesign`。只生成用户需要的阶段与变体。攻略编成、自定编成、固定实例练级和动态支援分别声明自己的依据，不把旧任务的船、等级、舰队编号或准备阈值隐式套用。

普通海域任务的推进顺序与完成判据使用 [跨海域接续](跨海域接续.md) 的显式计划，和路线证据分别核对；接续计划不从文件中的排列或历史方案隐式推断。远征使用独立的计划结构，见 [远征配置](远征配置.md)。概率分析是可选工具，其输入状态与能力限制见 [活动出击达成率分析](活动出击达成率分析.md)；无法可靠估算概率不等同于路线或配置必然不可执行，但实际执行所必需的事实仍须验证。

最终配置只引用本次核实的事实。来源、采集时间、适用地图与阶段、已知缺项及人工操作点应在本次计划和配置备注中可追溯。
